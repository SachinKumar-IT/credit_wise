## 🚀 About the Project

**CreditWise** explores how applicant-related data can be processed and used to predict whether a loan application is likely to be approved.

The project covers the complete basic ML workflow:

**Data → Preprocessing → EDA → Feature Engineering → Model Training → Evaluation**

---

## 📊 Model Performance

The project uses a **Gaussian Naive Bayes** classifier.

| Metric       |      Score |
| :----------- | ---------: |
| 🎯 Accuracy  | **86.50%** |
| 🔍 Precision | **80.36%** |
| 📈 Recall    | **73.77%** |
| ⚡ F1 Score   | **76.92%** |

---

## 🧠 What I Worked On

* 🧹 Handled missing values
* 📊 Performed Exploratory Data Analysis
* 🔤 Encoded categorical features
* ⚖️ Applied feature scaling using `StandardScaler`
* 🤖 Trained a **Gaussian Naive Bayes** model
* 📏 Evaluated the model using multiple classification metrics
